# Notch Two changelog

## v0.1.0-preview.4

- Complete English and Russian translations across Notch Two settings and notch controls.
- Offer five interface languages in General settings, alongside the system default.
- Switch older British English selections to English and other retired selections to the system default.

## v0.1.0-preview.3

- Open the source chat from any free area of a Telegram notification card. If macOS can no longer open the original notification, keep the card visible with an explanation.
- Extend the optional Network HUD with Wi-Fi changes, route loss and recovery, and an optional network name.
- Preserve a Shelf-owned file when a remaining bookmark cannot be resolved.

Earlier versions are listed in [GitHub Releases](https://github.com/kkonstantin08/notch-two/releases).
