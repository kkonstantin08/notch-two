# Contributing

Issues and pull requests for Notch Two are welcome. Keep changes focused, preserve the separate `local.notchtwo.app` identity and existing Notch Two preferences, and retain upstream and third-party notices.

Before opening a pull request on macOS with Xcode 26 or later, run:

```sh
./scripts/test.sh
./scripts/build.sh
```

Describe the user-visible change and the checks you ran. Do not include local traces, personal data, or files from `.build/`.
